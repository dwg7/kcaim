# /procedures/five-factors-seven-assessments
- status: 原文=verified / 現代への当てはめ=derived
- 原文(始計第一): 「經之以五事，校之以七計」。五事は「一曰道，二曰天，三曰地，四曰將，五曰法」。七計は「主孰有道？將孰有能？天地孰得？法令孰行？兵眾孰強？士卒孰練？賞罰孰明？」
- 原文の位置づけ: 戦う前に、敵味方を同じ観点で比べ、勝負の見通しを立てる手順。「廟算」で得算が多いほど勝つ、と述べる。
- 解釈(derived, AI下書き): 意思決定の前に、自分と相手を**同じ項目で並べて比べる**。項目は、①共有された目的(道)、②時機(天)、③環境(地)、④担い手の力量と徳目(將)、⑤制度(法)。
- 限界: 原文は軍事上の評価項目であり、これを組織の診断表に直すのは解釈である。項目の置き換え方に唯一の正解はない。

# /decision-support/cost-of-prolonged-action
- status: 原文=verified / 解釈=derived
- 原文(作戰第二): 「兵貴勝，不貴久」「夫兵久而國利者，未之有也」「故不盡知用兵之害者，則不能盡知用兵之利也」
- 原文の位置づけ: 軍が長く出ると、費用がかさみ、他の勢力につけ込まれる、という議論。
- 解釈(derived): 長引く取り組みは、固定の費用を払い続け、機会費用も生む。着手前に**害(長期化の費用)を先に数える**。
- 同じ篇の別の論点: 「因糧於敵」(敵の資源を使う)、「勝敵而益強」(勝つことで自分も強くなる形にする)。これらは、取り組みを重荷にせず、資源を取り込みながら進める発想として読める。(derived)
- 限界: 原文の「久」は軍事行動の長期化であり、継続的な事業や共同体の維持を論じているわけではない。

# /decision-support/win-without-fighting

- 原文(謀攻第三): 「不戰而屈人之兵，善之善者也」「上兵伐謀，其次伐交，其次伐兵，其下攻城」「必以全爭於天下」

# /decision-support/alignment-and-incentive
- status: 原文=verified / 解釈=derived
- 原文: 「上下同欲者勝」(謀攻第三)。「犯之以利，勿告以害」(九地第十一)。「趨諸侯者以利」「雜於利而務可信也」(九變第八)。「吳人與越人相惡也，當其同舟而濟。遇風，其相救也，如左右手」(九地第十一)。「以利動之」(兵勢第五)。
- 原文の位置づけ: 上下の目的が揃うことが勝ちの条件の1つ。人を動かすのは利。仲が悪い者同士でも、同じ危機を共有すれば互いを助ける、という比喩。
- 解釈(derived): 連携しない方が各自に得な状況では、①**共有される危機や利害の構造を可視化**する、②連携に参加する**個々の利**を設計する、③約束を守る**信**を積む、の3つが手がかりになる。
- 限界: 孫子の想定は、君主と将軍・軍の上下関係であり、**対等な主体の自発的連携**ではない。「攜手若使一人，不得已也」(九地)は、強制に近い状況を述べる。対等な主体にそのまま当てはめてはならない。

# /decision-support/delegation-and-center
- status: 原文=verified / 解釈=derived
- 原文: 「治衆如治寡，分數是也」(兵勢第五)。「將能而君不御者勝」(謀攻第三)。「君命有所不受」(九變第八)。「戰道必勝，主曰無戰，必戰可也」(地形第十)。「是為縻軍」(謀攻第三、君主が軍の進退に口を出すこと)。「故兵以詐立，以利動，以分合為變者也」(軍爭第七)。
- 解釈(derived): 中央が現場に口を出しすぎると、組織が動けなくなる(縻軍)。現場の判断が優れる条件(状況を直接見ている、戦機が短い)では、権限を委ねる。一方、**全体で統一する必要がある領域**(金鼓旌旗で耳目を一つにする、軍爭第七)もあり、両方を使い分ける。
- 限界: 孫子は「分散と集中」の**価値の比較**を論じていない。条件の整理は解釈である。分散組織の経済的価値は範囲外。

# /decision-support/decide-to-engage
- status: 原文=verified / 解釈=derived
- 原文: 「勝兵先勝而後求戰，敗兵先戰而後求勝」(軍形第四)。「非利不動，非得不用，非危不戰」「主不可以怒而興師，將不可以慍而致戰」「合於利而動，不合於利而止」「怒可以復喜……亡國不可以復存」(火攻第十二)。「兵貴勝，不貴久」(作戰第二)。「窮寇勿迫」「圍師必闕」「歸師勿遏」(軍爭第七)。「死地則戰」(九地第十一)。
- 位置づけ: 衝突を決める前の条件(利・得・危)と、感情による決断の戒め。決めた後の戦い方の限定(窮寇勿迫など)。
- 規範の緊張(消さずに残す): 速く終えよ(作戰、九地の「兵之情主速」)と、追い詰めた相手に迫るな(窮寇勿迫)は、一見ぶつかる。窮地に追い込まれた相手は死に物狂いで戦うので、**徹底は、味方に有利とは限らない**、という読み方ができる。(derived)
- 条件つきの徹底: 「死地則戰」は、**自分が**退路のない状況に置かれたときは戦うほかない、という意味に読める。自分たちが死地にあるか、相手を死地に追い込もうとしているかで、答えが逆になる。(derived)
- 限界: 孫子は、決心した衝突を「徹底的にやるべきか」を一般論としては述べていない。

# /decision-support/orthodox-and-unorthodox
- status: 原文=verified / 解釈=derived
- 原文: 「凡戰者，以正合，以奇勝」「戰勢不過奇正，奇正之變，不可勝窮也。奇正相生，如循環之無端」(兵勢第五)。「令之以文，齊之以武，是謂必取。令素行以教其民，則民服」(行軍第九)。「故兵無成勢，無恒形，能因敵變化而取勝者，謂之神」(虛實第六)。「其戰勝不復，而應形於無窮」(虛實第六)。
- 解釈(derived): 訓練された通りに行うこと(正)と、創造的であること(奇)は、**対立ではなく、組み合わせの関係**として書かれている。正が基礎にあり、奇が勝負を決め、2つは互いに変わり合う。訓練(令素行)は、現場が動けるようにする土台。同じ勝ち方を繰り返さない(戰勝不復)。
- 限界: 孫子は訓練の方法を述べていない。
- 版の注意: 「兵無成勢，無恒形」は、この版の本文。他の版で異なる字句(「常勢」など)で伝わっている可能性があり、未確認。→ `/open-questions/textual-variants`

# /decision-support/concealment-and-probing
- status: 原文=verified / 解釈=derived
- 原文: 「兵者，詭道也。故能而示之不能，用而示之不用」(始計第一)。「形兵之極，至於無形。無形，則深間不能窺，智者不能謀」「人皆知我所以勝之形，而莫知吾所以制勝之形」(虛實第六)。「能愚士卒之耳目，使之無知」(九地第十一)。「策之而知得失之計，作之而知動靜之理，形之而知死生之地，角之而知有餘不足之處」(虛實第六)。「而愛爵祿百金，不知敵之情者，不仁之至也」(用間第十三)。
- 解釈(derived): 相手に自分の力や意図を読ませない(隠す)ことは、有効な手段として書かれている。同時に、相手の様子を**試して探る**(策・作・形・角)ことも勧められる。
- 隠すことの費用に関する原文の直接の記述: **ない**。ただし、次の点は読み取れる(derived): ①味方にも隠すと(愚士卒之耳目)、味方の理解と納得が損なわれうる、②相手の情報を取るための費用を惜しむことは「不仁之至」とされ、**知らないことの費用**は大きいと見ている。
- 限界: 「韜晦」は孫子の語ではない。→ `/decision-support/term-mapping`。孫子の「詭道」は敵に対する欺瞞であり、**誠実さの価値判断**は述べない。企業内の説明責任と両立するかは、孫子から決められない。

# /decision-support/term-mapping
- status: derived(AI下書き)
- 目的: 現代の語と孫子の語が1対1でないときに、**対応の根拠と限界**を示す。

# /inventory/findings-for-the-format
- この作成作業で見つかった、KCAIM の形式・運用への示唆(仮説。他のインスタンスで検証するまで確定しない):
- 境界テスト: 範囲外の質問に正しく断る振る舞いを、受け入れテストの結果として表す方法が要る。
- 語の対応: 現代語と原典の語が1対1でないとき、対応の根拠と限界を持つオブジェクトが要る。
- 引用の検証: 記憶による引用は誤りうる。固定した版に照らす規則が要る。
- 版の固定: 取得した版(oldid)と取得日を `/sources/` に残すことで、再現できる。
- 規範の緊張: 一見矛盾する規範を、片方に寄せず並べて残す書き方が要る。
