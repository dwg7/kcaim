# /procedures/five-factors-seven-assessments
- status: 原文=verified / 現代への当てはめ=derived
- 原文(始計第一): 「經之以五事，校之以七計」。五事は「一曰道，二曰天，三曰地，四曰將，五曰法」。七計は「主孰有道？將孰有能？天地孰得？法令孰行？兵眾孰強？士卒孰練？賞罰孰明？」
- 原文の位置づけ: 戦う前に、敵味方を同じ観点で比べ、勝負の見通しを立てる手順。「廟算」で得算が多いほど勝つ、と述べる。
- 解釈(derived, AI下書き): 意思決定の前に、自分と相手を**同じ項目で並べて比べる**。項目は、①共有された目的(道)、②時機(天)、③環境(地)、④担い手の力量と徳目(將)、⑤制度(法)。
- 限界: 原文は軍事上の評価項目であり、これを組織の診断表に直すのは解釈である。項目の置き換え方に唯一の正解はない。

# /decision-support/cost-of-prolonged-action
- status: 原文=verified / 解釈=derived
- 原文(作戰第二): 「兵貴勝，不貴久」「夫兵久而國利者，未之有也」「故不盡知用兵之害者，則不能盡知用兵之利也」
- 原文の位置づけ: 軍が長く出ると、費用がかさみ、他の勢力につけ込まれる、という議論。
- 解釈(derived): 長引く取り組みは、固定の費用を払い続け、機会費用も生む。着手前に**害(長期化の費用)を先に数える**。
- 同じ篇の別の論点: 「因糧於敵」(敵の資源を使う)、「勝敵而益強」(勝つことで自分も強くなる形にする)。これらは、取り組みを重荷にせず、資源を取り込みながら進める発想として読める。(derived)
- 限界: 原文の「久」は軍事行動の長期化であり、継続的な事業や共同体の維持を論じているわけではない。

# /decision-support/alignment-and-incentive
- status: 原文=verified / 解釈=derived
- 原文:
  - 「上下同欲者勝」(謀攻第三)。
  - 「犯之以利，勿告以害」(九地第十一)。
  - 「趨諸侯者以利」「雜於利而務可信也」(九變第八)。
  - 「吳人與越人相惡也，當其同舟而濟。遇風，其相救也，如左右手」(九地第十一)。
  - 「以利動之」(兵勢第五)。
- 原文の位置づけ: 上下の目的が揃うことが勝ちの条件の1つ。人を動かすのは利。仲が悪い者同士でも、同じ危機を共有すれば互いを助ける、という比喩。
- 解釈(derived): 連携しない方が各自に得な状況では、①**共有される危機や利害の構造を可視化**する、②連携に参加する**個々の利**を設計する、③約束を守る**信**を積む、の3つが手がかりになる。
- 限界: 孫子の想定は、君主と将軍・軍の上下関係であり、**対等な主体の自発的連携**ではない。「攜手若使一人，不得已也」(九地)は、強制に近い状況を述べる。対等な主体にそのまま当てはめてはならない。

  - 「君命有所不受」(九變第八)。

# /decision-support/decide-to-engage
- status: 原文=verified / 解釈=derived
- 原文:
  - 「勝兵先勝而後求戰，敗兵先戰而後求勝」(軍形第四)。
  - 「非利不動，非得不用，非危不戰」「主不可以怒而興師，將不可以慍而致戰」「合於利而動，不合於利而止」「怒可以復喜……亡國不可以復存」(火攻第十二)。
  - 「兵貴勝，不貴久」(作戰第二)。
  - 「窮寇勿迫」「圍師必闕」「歸師勿遏」(軍爭第七)。
  - 「死地則戰」(九地第十一)。
- 位置づけ: 衝突を決める前の条件(利・得・危)と、感情による決断の戒め。決めた後の戦い方の限定(窮寇勿迫など)。
- 規範の緊張(消さずに残す。一覧は `/decision-support/internal-tensions` の1・3・8): 窮地に追い込まれた相手は死に物狂いで戦うので、**徹底は、味方に有利とは限らない**、という読み方ができる。(derived)
- 条件つきの徹底: 「死地則戰」は、**自分が**退路のない状況に置かれたときは戦うほかない、という意味に読める。自分たちが死地にあるか、相手を死地に追い込もうとしているかで、答えが逆になる。(derived)
- 限界: 孫子は、決心した衝突を「徹底的にやるべきか」を一般論としては述べていない。

# /decision-support/orthodox-and-unorthodox
- status: 原文=verified / 解釈=derived
- 原文:
  - 「凡戰者，以正合，以奇勝」「戰勢不過奇正，奇正之變，不可勝窮也。奇正相生，如循環之無端」(兵勢第五)。
  - 「令之以文，齊之以武，是謂必取。令素行以教其民，則民服」(行軍第九)。
  - 「故兵無成勢，無恒形，能因敵變化而取勝者，謂之神」(虛實第六)。
  - 「其戰勝不復，而應形於無窮」(虛實第六)。
- 解釈(derived): 訓練された通りに行うこと(正)と、創造的であること(奇)は、**対立ではなく、組み合わせの関係**として書かれている。正が基礎にあり、奇が勝負を決め、2つは互いに変わり合う。訓練(令素行)は、現場が動けるようにする土台。同じ勝ち方を繰り返さない(戰勝不復)。
- 限界: 孫子は訓練の方法を述べていない。
- 版の注意: 「兵無成勢，無恒形」は、この版(孫子兵法 oldid=7906064)の本文。十一家注孫子(虛實篇の副ページ)の本文は「故兵無常勢」「水無常形」で、**字句が異なる**(確認済み。→ `/open-questions/textual-variants`)。意味の読みは、どちらの字句でも、敵に応じて形を変える趣旨と読める(derived)。

# /decision-support/concealment-and-probing
- status: 原文=verified / 解釈=derived
- 原文:
  - 「兵者，詭道也。故能而示之不能，用而示之不用」(始計第一)。
  - 「形兵之極，至於無形。無形，則深間不能窺，智者不能謀」「人皆知我所以勝之形，而莫知吾所以制勝之形」(虛實第六)。
  - 「能愚士卒之耳目，使之無知」(九地第十一)。
  - 「策之而知得失之計，作之而知動靜之理，形之而知死生之地，角之而知有餘不足之處」(虛實第六)。
  - 「而愛爵祿百金，不知敵之情者，不仁之至也」(用間第十三)。
- 解釈(derived): 相手に自分の力や意図を読ませない(隠す)ことは、有効な手段として書かれている。同時に、相手の様子を**試して探る**(策・作・形・角)ことも勧められる。
- 隠すことの費用に関する原文の直接の記述: **ない**。ただし、次の点は読み取れる(derived): ①味方にも隠すと(愚士卒之耳目)、味方の理解と納得が損なわれうる、②相手の情報を取るための費用を惜しむことは「不仁之至」とされ、**知らないことの費用**は大きいと見ている。
- 限界: 「韜晦」は孫子の語ではない。→ `/decision-support/term-mapping`。孫子の「詭道」は敵に対する欺瞞であり、**誠実さの価値判断**は述べない。企業内の説明責任と両立するかは、孫子から決められない。

# /decision-support/nine-terrains
- status: 原文=verified / 当てはめ=derived
- 原文(九地第十一)の定義: 「諸侯自戰其地者，為散地」「入人之地而不深者，為輕地」「我得則利，彼得亦利者，為爭地」「我可以往，彼可以來者，為交地」「諸侯之地三屬，先至而得天下之衆者，為衢地」「入人之地深，背城邑多者，為重地」「山林、險阻、沮澤，凡難行之道者，為圮地」「所由入者隘，所從歸者迂，彼寡可以擊吾之衆者，為圍地」「疾戰則存，不疾戰則亡者，為死地」
- 原文の対処: 「散地則無戰，輕地則無止，爭地則無攻，交地則無絕，衢地則合交，重地則掠，圮地則行，圍地則謀，死地則戰」
- 同じ篇の別の対処(将が兵に対して取る態度): 「衢地，吾將固其結」「爭地，吾將趨其後」「交地，吾將謹其守」
- 九變第八にも似た列がある: 「圮地無舍，衢地合交，絕地無留，圍地則謀，死地則戰」。**九地篇の九つとは項目が異なる**(絕地を含み、散・輕・爭・交・重を含まない)。2つの列の関係について、十一家注の張預は、九變の列は九地の「變」(対処)の大略にすぎない、と述べる(`reported`。→ `/decision-support/commentator-views`)。
- 語の曖昧さ: 軍形第四の「藏於九地之下」の「九地」は、ここでいう九つの地形の分類とは別の意味(深い地の底)に読める。同じ字面でも同じ概念とは限らない。(derived)
- 解釈(derived, AI下書き): この分類は、**地理上の場所そのものではなく、自分と相手と第三者の位置関係**による。同じ対象が、見方により別の地になりうる。
- 当てはめの手順(derived): ①誰と誰が、その対象に接しているか(三方以上か)、②誰が得ても他も得られるか(爭地)、③双方が行き来できるか(交地)、④自分の側に退路があるか(死地・圍地)、の順に問う。
- 限界: 現代の対象(産業・技術・データなど)の**実際の位置関係**は、孫子から決められない。当てはめは類比であり、対象の側の事実は、範囲外として別に確かめる必要がある。

# /decision-support/comparison-sunzi-hacker-ethic
- 範囲: 示唆のみ(範囲外)
- status: **仮説(recalled と、ページ要約に基づく言い換え)**。孫子の側は verified、ハッカー倫理の側は出典の要約と記憶。結果の上限は partial

- ハッカー倫理の側の内容(`partial`。CCC のページの要約に基づく言い換え。原文の文言は確かめていない): ①計算機と、世界の仕組みを知る手がかりへのアクセスは、制限されるべきでない。②情報は自由であるべき。③権威を疑い、分散を促す。④人は、学歴などではなく、行いで評価される。⑤計算機で芸術と美を作れる。⑥計算機は生活をよくしうる。⑦他人のデータを散らかさない。⑧公共のデータは使えるようにし、私的なデータは守る。
- 衝突しそうな点(仮説):
  1. **情報の扱い**。ハッカー倫理②は情報の自由。孫子は、勝ち筋を先に伝えられないものとし(「此兵家之勝，不可先傳也」始計第一)、自分の形を読ませない(「形人而我無形」虛實第六)。**情報を隠すか開くかで、基本の姿勢が逆**。
  2. **手段の許容**。ハッカー倫理⑦は他人のデータを散らかさないことを求める。孫子は、欺瞞と攪乱を手段として許容する(「亂而取之」「攻其無備，出其不意」始計第一)。
  3. **権威**。ハッカー倫理③は権威への不信。孫子の枠組みは、君主と将軍の上下関係(上下同欲、君命)である。ただし、孫子も、現場への委任(「將能而君不御者勝」謀攻第三、「君命有所不受」九變第八)を認めており、**完全な対立ではない**。
- 高め合いそうな点(仮説):
  1. **自分の弱点を先に探す**。孫子は「無恃其不攻，恃吾有所不可攻也」(九變第八)、「不可勝在己」(軍形第四)と、自分の側の備えを頼む。ハッカー倫理の、仕組みを調べ、壊れ方を学ぶ姿勢(①、`recalled`)は、これを実践する方法になりうる。
  2. **現場を知る**。孫子は「不用鄉導者，不能得地利」(軍爭第七)。ハッカー倫理は、実際に触れて知ることを重んじる(①)。
  3. **実力による評価**。孫子の「進不求名」(地形第十)、「無智名，無勇功」(軍形第四)と、ハッカー倫理④の、行いで評価する姿勢は、地位や名声より実質を見る点で近い。
  4. **欠けている部分を補う**。孫子は、目的の是非や倫理を決めない(→ `what-sunzi-can-and-cannot-decide`)。ハッカー倫理は、明示的な倫理(⑦、⑧)を持つ。孫子の手段の議論に、倫理の枠を与えうる。逆に、ハッカー倫理は、孫子の事前評価と慎重さ(「非利不動」火攻第十二)から、動く前の評価の規律を得られる。
- 確かめるべきこと: ハッカー倫理の側の言い換えが、CCC の版、レヴィの版のどちらの文言に近いか。また、各項目の意図。出典の利用条件(→ `/open-questions/hacker-ethic-text`)。

- 原文(軍爭第七): 「其疾如風，其徐如林，侵掠如火，不動如山，難知如陰，動如雷震」「懸權而動」「先知迂直之計者勝」。

- 規範の緊張: 速さを重んじる句(九地)と、動かないこと(不動如山)を重んじる句が並ぶ。調子の切り替えが要点と読める。(derived)

# /decision-support/commentator-views
- status: `reported`(注釈者の見解。孫子の本文自体の定めではない)
- 出典: ウィキソース「十一家注孫子」の副ページ(`/sources/other-witnesses` を参照)。注の著者名は、ページが付した帰属。
- 優先順位: 注釈は `/authorities/precedence` の規則3により、原文と区別する。ここでは、**本文の読みが割れる箇所で、注釈者がどう読んだか**だけを記す。
- 見解1(虛實第六の「勝可爲也」と、軍形第四の「勝可知而不可爲」の矛盾の調停):
  - 十一家注の本文: 「故曰︰勝可爲也」。
  - 杜牧: 「爲勝在我，故言可爲也」。
  - 張預: 「爲勝在我故也」。軍形の句は「攻守之勢」を論じ、敵に備えがあれば「不可必爲」と述べる。虛實の句は、越の兵に即して、「度越人必不能知所戰之地日」ゆえに「可爲」と述べる、と調停する。
  - 解釈(derived): 2つの句は、**条件が違う**(敵の備えの有無、敵が戦地と戦日を知っているか)と読めば矛盾しない、という注釈者の読み。他の読みがありうるかは、確かめていない。
- 見解2(九變の列と九地の関係):
  - 張預: 「止陳五事者，舉其大略也」。九地篇も「唯言六事」で「亦陳其大略」。「九變爲九地之變」と読み、根拠として九變篇の「雖知地形，不能得地之利」と、九地篇の「九地之變，屈伸之利」を挙げる。
  - 張預の別の整理: 「凡地有勢有變」。九地篇の前半に述べたのは「勢」、後半に述べたのは「變」。
  - 解釈(derived): 九變の列が九地の分類と食い違うのは、前者が「變(対処)」の大略だから、という読み。孫子の本文が自らそう述べているわけではない。
- 限界: 注釈者は後世(宋代までの人々)の読み手であり、孫子本人の意図を知る立場ではない。

# /inventory/findings-for-the-format
- この作成作業で見つかった、KCAIM の形式・運用への示唆(仮説。他のインスタンスで検証するまで確定しない):
- 境界テスト: 範囲外の質問に正しく断る振る舞いを、受け入れテストの結果として表す方法が要る。
- 語の対応: 現代語と原典の語が1対1でないとき、対応の根拠と限界を持つオブジェクトが要る。
- 引用の検証: 記憶による引用は誤りうる。固定した版に照らす規則が要る。
- 版の固定: 取得した版(oldid)と取得日を `/sources/` に残すことで、再現できる。
- 規範の緊張: 一見矛盾する規範を、片方に寄せず並べて残す書き方が要る。
- 欠けの種類: テストの missing を、**取り込み不足**(出典にあるが宇宙に入れていない)と、**出典の限界**(出典自体が答えを持たない)に分けて書く。前者は拡充で埋まり、後者は別の出典か、範囲外の宣言で扱う。(run-2026-10-27 で発見)
- 実行者の独立性: 宇宙を作った主体が自分でテストを解くと偏る。実行者(誰が、何を見て答えたか)を結果に記録し、盲検の実行を別に行う。(盲検の実施で、状態語の衝突、中間型の範囲外、範囲の読みにくさという欠陥が見つかった。→ run-2-blind-2026-10-27)
- 盲検の準備: テストの節と過去の結果を取り除いたコピーを渡す。取り除きの漏れ(経緯の記述など)が残る点に注意。
