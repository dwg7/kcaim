## 旧称 kcaim について

miso は、旧称を kcaim といいます。KCAI(Knowledge Co-Created with AI)の実践です。

KCAIM とは Knowledge Co-created with AI, in a single Markdown file です。

エンタープライズCopilotが持ち歩く業務宇宙 Markdown ファイルの概念です。

A concept for enterprise knowledge universes carried by AI assistants.
